= Inicio rápido para NetApp Console en modo estándar
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Comience a utilizar la NetApp Console (SaaS) preparando la red para la consola, registrándose y creando una cuenta y utilizando el asistente de la consola para configurar la funcionalidad inicial.

Accede a una consola basada en web que está alojada como un producto de software como servicio (SaaS) de NetApp. Puede utilizar la consola para administrar su entorno de almacenamiento en nube híbrida y utilizar los servicios de datos de NetApp .

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"] link:reference-networking-saas-console.html["Prepara la red para usar la NetApp Console"]
[role="quick-margin-para"]
Asegúrate de que los ordenadores que acceden a la consola de NetApp tengan acceso de red a los endpoints requeridos.

link:reference-networking-saas-console.html["Aprende cómo preparar la red para la NetApp Console."]

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dos"] link:task-sign-up-saas.html["Regístrate y crea una organización"]
[role="quick-margin-para"]
Ve a https://console.netapp.com["NetApp Console"^] y regístrate. Si te piden crear una organización y crees que ya existe una organización para tu empresa, cierra el cuadro de diálogo y avísale al administrador de tu organización. Si actualmente no hay un administrador de organización para tu empresa, puedes reclamar este rol. link:task-user-settings.html#contact-admin["Aprenda cómo comunicarse con un administrador de la organización."^]

[role="quick-margin-para"]
En este punto, ya has iniciado sesión y puedes usar el asistente de NetApp para empezar a configurar la Console. Para empezar, asocia tu cuenta de NetApp Support Site y un agente de la Console para habilitar toda la funcionalidad.

Si elige no utilizar el asistente de NetApp o instalar un agente de consola, puede comenzar a administrar el almacenamiento y utilizar servicios como Digital Advisor, Amazon FSx para ONTAP, Azure NetApp Files y más. link:concept-agents.html["Descubra lo que puede hacer sin un agente de consola"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tres"] Asocie su cuenta del sitio de soporte de NetApp (NSS)
Asociar su cuenta del sitio de soporte de NetApp (NSS) con la consola le permite administrar sus licencias y suscripciones más fácilmente, así como acceder a recursos de soporte directamente desde la consola.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Cuatro"] Crear un agente de consola
[role="quick-margin-para"]
Las funciones de administración de almacenamiento avanzada y algunos servicios de datos de NetApp requieren que instale un agente de consola.  El agente de la consola permite que la consola administre recursos y procesos dentro de su entorno de nube híbrida.

[role="quick-margin-para"]
Puede crear un agente de consola en su nube o red local.

[role="quick-margin-list"]
* link:concept-agents.html["Obtenga más información sobre cuándo se requieren los agentes de consola y cómo funcionan"]
* link:concept-install-options-aws.html["Aprenda a crear un agente de consola en AWS"]
* link:concept-install-options-azure.html["Aprenda a crear un agente de consola en Azure"]
* link:concept-install-options-google.html["Aprenda a crear un agente de consola en Google Cloud"]
* link:task-install-agent-on-prem.html["Aprenda a crear un agente de consola local"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinco"] Agregar un sistema de almacenamiento a la consola
[role="quick-margin-para"]
Dentro de la NetApp Console, puede agregar o descubrir sistemas de almacenamiento para administrar su entorno de almacenamiento en nube híbrida. Utilice el asistente de NetApp para agregar su primer sistema de almacenamiento.


TIP: Si instala un agente de consola en AWS, Microsoft Azure o Google Cloud, la consola descubre automáticamente información sobre los buckets de Amazon S3, Azure Blob Storage o Google Cloud Storage en la ubicación donde está instalado el agente. Estos sistemas se agregan automáticamente a la página *Sistemas*.

* link:https://docs.netapp.com/us-en/storage-management-ontap-onprem/task-discovering-ontap.html["Aprenda a descubrir un sistema ONTAP"]
* link:https://docs.netapp.com/us-en/storage-management-storagegrid/task-discover-storagegrid.html["Aprenda a descubrir un sistema StorageGRID"]
* link:https://docs.netapp.com/us-en/storage-management-e-series/task-discover-e-series.html["Aprenda a descubrir un sistema de la Serie E"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Seis"] link:task-subscribe-standard-mode.html["Suscríbete a los NetApp Intelligent Services (opcional)"]
[role="quick-margin-para"]
Regístrate en NetApp Intelligent Services a través de tu proveedor de nube para facturación por horas (PAYGO) o anual. Una suscripción incluye NetApp Backup and Recovery, Cloud Volumes ONTAP, NetApp Ransomware Resilience, NetApp Disaster Recovery y NetApp Data Classification.

[NOTE]
====
NetApp Cloud Tiering ya no está disponible para la compra o renovación de licencias desde el 26 de abril de 2026.

Los clientes existentes pueden seguir utilizando y recibiendo asistencia para NetApp Cloud Tiering hasta que caduque su contrato de suscripción o licencia. Una vez caducada la suscripción, los clientes dejarán de tener acceso a las funciones o a la asistencia de NetApp Cloud Tiering.

NetApp recomienda que los clientes trabajen con su representante de NetApp para realizar la transición de sus licencias de tiering existentes a licencias de ONTAP FabricPool, que proporcionan la funcionalidad para el tiering de datos en ONTAP. Para obtener más información sobre cómo configurar el tiering de datos en ONTAP utilizando FabricPool, consulta link:https://docs.netapp.com/us-en/ontap/fabricpool/install-license-aws-azure-ibm-task.html["Instalar una licencia FabricPool en un cluster ONTAP"^].
