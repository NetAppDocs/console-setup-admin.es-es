= Ver los sistemas asociados a diferentes agentes de la NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Si tu organización utiliza varios agentes de Console, puedes cambiar entre ellos para ver los sistemas asociados a un agente específico.

Para usuarios con el rol Org admin, esto es útil cuando implementas tu estrategia de gestión de recursos. Puedes cambiar a un agente diferente cuando descubras sistemas de almacenamiento para asociar automáticamente esos sistemas con el agente que está en el mismo entorno.

Para los administradores de almacenamiento, cambia entre agentes para gestionar los sistemas que están asociados a cada agente.

Por ejemplo, en un entorno multicloud, tu organización puede tener un agente en AWS y otro en Google Cloud. Cambia entre estos agentes para gestionar los sistemas Cloud Volumes ONTAP en los respectivos entornos cloud.


NOTE: Esta opción no está disponible cuando se visualiza la NetApp Console desde la interfaz de usuario local del agente.

.Paso
. Selecciona *Almacenamiento* > *Administración* > *Sistemas*.
. Seleccione el icono de Agentes de la consola (image:icon-agent.png["icono de agente"] ) en la parte superior derecha para ver la lista de agentes disponibles.
+
image:screenshot-connector-switch.png["Una captura de pantalla que muestra el ícono de Agentes en el encabezado y la acción Cambiar."]



.Resultado
La consola se actualiza y muestra los sistemas asociados con el agente seleccionado.
