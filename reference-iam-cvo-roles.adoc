= Roles de acceso de Cloud Volumes ONTAP en NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Puedes asignar los siguientes roles a los usuarios para darles acceso a Cloud Volumes ONTAP dentro de la consola. Los roles de Cloud Volumes ONTAP te dan la flexibilidad de asignar a los usuarios un rol específico para las tareas que necesitan realizar dentro de tu organización. Cómo asignes los roles depende de tu propio negocio y de tus prácticas de gestión del almacenamiento.

Cloud Volumes ONTAP utiliza los siguientes roles:

* *Administrador de Cloud Volumes ONTAP*: Ofrece acceso completo a todas las operaciones de Cloud Volumes ONTAP.
* *Operador de Cloud Volumes ONTAP*: Realiza operaciones importantes de almacenamiento, como descubrir y gestionar sistemas Cloud Volumes ONTAP, incluyendo añadir volúmenes, agregados, instantáneas y replicaciones, modificar algunas configuraciones y actualizar las versiones de Cloud Volumes ONTAP.
* *Visor de Cloud Volumes ONTAP*: Proporciona acceso de solo lectura a la información de Cloud Volumes ONTAP. Este rol no puede realizar ninguna operación activa. Es posible que algunas pestañas y pantallas que contienen información de configuración no estén disponibles para los usuarios con este rol.


Para obtener detalles sobre todos los roles de acceso de NetApp Console, consulta link:reference-iam-predefined-roles.html["roles de acceso"].



[[how-role-changes-take-effect]]
== Cómo se aplican los cambios de rol

Cloud Volumes ONTAP aplica el control de acceso basado en roles (RBAC) mediante una caché local de cada asignación de roles. La caché se actualiza automáticamente cada hora. Si se asigna un nuevo rol o se modifica uno ya existente, el cambio puede tardar hasta una hora en surtir efecto. Una vez completada la actualización, la consola habilita los flujos de trabajo permitidos por ese rol.


NOTE: Cuando se implementa un agente de Console por primera vez, o cuando se actualiza un agente de Console ya existente a la versión 4.9.0 o posterior, Console ejecuta un proceso de configuración inicial único que asigna roles de Cloud Volumes ONTAP a los usuarios existentes de la organización. Este proceso puede tardar hasta 30 minutos en completarse.
