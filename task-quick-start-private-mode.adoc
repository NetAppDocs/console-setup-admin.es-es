= Inicio rápido para NetApp Console en modo privado
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Puedes instalar NetApp Console en las instalaciones o en un entorno de nube segura. El modo privado se usa normalmente con entornos en las instalaciones que no tienen conexión a internet y con regiones de nube segura, que incluyen https://aws.amazon.com/federal/secret-cloud/["AWS Secret Cloud"^], https://aws.amazon.com/federal/top-secret-cloud/["AWS Top Secret Cloud"^] y https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-dod-il6["Azure IL6"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"] link:task-prepare-private-mode.html["Prepárese para el despliegue"]
[role="quick-margin-list"]
. Prepare un host Linux dedicado que cumpla con los requisitos de CPU, RAM, espacio en disco, herramienta de orquestación de contenedores y más.
. Configura una red que proporcione acceso a las redes de destino.
. Para las implementaciones en la nube, configura los permisos en tu proveedor de la nube para que puedas asociar esos permisos con el agente de la Console después de instalar el software.


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dos"] link:task-install-private-mode.html["Implementar el agente de consola"]
[role="quick-margin-list"]
. Instala el agente de la consola en tu propio host Linux.
. Configura NetApp Console abriendo un navegador web e introduciendo la dirección IP del host Linux.
. Para las implantaciones en la nube, proporciona a NetApp Console los permisos que configuraste previamente.

== Funciones y servicios compatibles para NetApp Console en modo privado

En la siguiente tabla se enumeran las funciones de gestión del almacenamiento, los servicios de datos y las funciones administrativas disponibles en NetApp Console cuando lo instalas en modo privado. Las funciones difieren cuando instalas NetApp Console en la nube en comparación con tus instalaciones.
